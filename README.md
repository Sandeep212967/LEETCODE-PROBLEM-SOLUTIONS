# 🧠 Problem-Solving Strategy

For every problem:

### 1️⃣ Understand
- Read the problem carefully.
- Identify input and output.
- Check constraints.
- Understand examples.

### 2️⃣ Think
Try to identify the DSA pattern.

### 3️⃣ Brute Force
Find the simplest possible solution first.

### 4️⃣ Optimize
Ask:
- Can I reduce time complexity?
- Can a HashMap help?
- Can sorting help?
- Can Two Pointers help?
- Can Binary Search help?
- Is this a DP / Graph problem?

### 5️⃣ Code
Write the solution yourself.

### 6️⃣ Test
Check:
- Normal case
- Edge case
- Empty / minimum input
- Large input

### 7️⃣ Analyze
Write:
- Time Complexity
- Space Complexity

---

# ⏱️ 30-Minute Rule

| Time | Action |
|---|---|
| 0–10 min | Understand + think |
| 10–20 min | Brute force + examples |
| 20–30 min | Optimize |
| 30+ min | Take a hint / study approach |

> **Never copy a solution without understanding it.**

After seeing a solution:

**Close it → Code from memory → Test → Explain it in your own words**
